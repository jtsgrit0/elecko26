# PDF Analyzer

This skill analyzes PDF files to extract content, statistics, and data. It helps in:
1. Reading and extracting text from PDF files
2. Analyzing numerical data and statistics within PDFs
3. Comparing data points across different time periods
4. Summarizing key information from PDF documents

## Usage
- Use when a user asks to check or analyze content inside a PDF file
- Use when needing to extract specific numbers or data from PDF documents
- Use when comparing historical data with current figures from PDFs

## Example
When a user mentions a PDF file with candidate registration numbers and wants to analyze the data, this skill is invoked to process and understand the PDF content.
