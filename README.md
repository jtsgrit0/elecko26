# 🗳️ 2026 지방선거 필승 솔루션: Elecko26

> "선거는 데이터로 시작해서 데이터로 끝난다!" 

**Elecko26**은 단순한 정보 제공을 넘어, 12년간의 역대 지방선거 빅데이터와 실시간 뉴스 분석을 결합한 **2026 지방선거 통합 예측 플랫폼**입니다. 선거 캠프 관계자부터 유권자까지, 누구보다 빠르게 승리의 향방을 읽어보세요! 🚀✨

---

## ✨ 주요 기능 (Key Features)

### 🤖 24시간 잠들지 않는 인공지능 크롤러
*   매일 자정, 최신 선거 동향을 자동으로 수집합니다! 🌙
*   **지능형 인물 추출**: 전직 국무총리부터 지역구 예비후보까지, 직함과 문맥을 분석하여 이름만 쏙쏙 뽑아냅니다. 🎯
*   **실시간 정당 트렌드**: 더불어민주당, 국민의힘은 물론 조국혁신당, 개혁신당, 기본소득당까지 공식 브랜드 정체성을 완벽하게 반영합니다! 🎨

### 📊 12년의 역사적 통찰 (5회~8회 지방선거)
*   **빅데이터 통합**: 1,700여 개 선거구의 방대한 데이터를 정규화하여 과거 지지율 트렌드를 분석합니다. 📈
*   **유권자 심리 분석**: 중앙선관위(NESDC)의 심층 리포트 PDF에서 '투표 관심도' 지표를 추출하여 예측 모델에 반영합니다. 🧠

### ⚔️ 원클릭 후보자 VS 비교 (Comparison)
*   보고 싶은 두 후보를 고르기만 하세요! 당선 가능성뿐만 아니라 **성과도, 활동도, 정책도, 언론도**를 한눈에 비교합니다.
*   각 정당의 공식 상징색과 로고를 적용한 **프리미엄 UI/UX**로 가독성을 극대화했습니다. 💎

---

## 🏗️ 강력한 기술적 기반 (Technical Foundation)

*   **Clean Architecture**: 데이터, 도메인, 프레젠테이션 계층의 완벽한 분리로 안정성과 확장성을 확보했습니다. 🏗️
*   **Robust Data Security**: 모든 원본 엑셀과 PDF는 철저히 제외하고, 정제된 JSON 데이터만을 버전 관리하여 저장소 효율을 극대화했습니다. 🔐
*   **Flutter Cross-Platform**: 모바일과 웹 어디서든 아름답고 부드러운 사용자 경험을 선공합니다. 📱💻
